SUBIN & AMALA — WEDDING WEBSITE
================================

HOW TO PREVIEW
1. Unzip this folder.
2. Open index.html in Chrome, or use VS Code + Live Server for the best local preview.
3. Internet is needed for the Google Fonts.

YOUR PHOTO PLACEHOLDERS
Put these files in the assets folder, keeping the exact filenames:
- cover.jpg       Main hero/cover photograph of the couple
- venue.png       Venue/location photograph (PNG as requested)
- gallery-01.jpg through gallery-10.jpg   Ten gallery photographs
- wedding-song.mp3  Your chosen song (optional)

The gallery shows designed placeholders until each photo is added.

RSVP / SEND REPLY
The form is configured for Netlify Forms. Deploy the folder to Netlify (or connect the project to a Git repository in Netlify). Netlify will collect replies in the site's Forms area. The form will not submit to a live inbox when simply opening index.html locally.

DEPLOY
Drag the unzipped folder (the folder containing index.html) into Netlify Drop, or connect it as a Git-based site. No build command is required; publish directory is the project root.
